## One Room, 100 Monsters — iOS

Offline iPhone and iPad build. iPhone opens in landscape; iPad supports portrait and landscape. Minimum supported iOS version: 15.

### Signing and installation

The attached IPA is unsigned. Sign it with an Apple certificate and a provisioning profile for bundle ID `com.lukayara.oneroom100monsters`. The provisioning profile must match the certificate and distribution method. Ad hoc profiles must include the target device UDIDs.
